# 🛡️ Chowkidar — Notice What Matters (Frontend)

This directory contains the Next.js React frontend for **Chowkidar**.

## 🚀 Quick Setup Instructions

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) or [http://localhost:3002](http://localhost:3002).

## 📄 Key Commands

- `npm run dev` — Launch Next.js development server
- `npm run build` — Compile TypeScript and build production bundle
- `npm run start` — Run production server

For detailed architectural details and key USPs, see `../README.md`.
